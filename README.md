# Dotify Widget

Виджет «сейчас играет» для главного экрана Android. Показывает обложку, трек, исполнителя и прогресс, даёт кнопки управления. Работает с Dotify и любым другим плеером, который показывает медиауведомление.

## Установка

1. Скачай `dotify-widget.apk` из [последнего релиза](../../releases/tag/latest) и установи (разреши установку из этого источника).
2. Открой приложение, нажми «Дать доступ к уведомлениям» и включи Dotify Widget.
3. Выбери оформление и добавь виджет кнопкой «Большой виджет 4×2» или «Мини-виджет 4×1».

## Оформления

Liquid Glass, Под обложку, Тёмное стекло, Светлая, AMOLED, Неон, Прозрачная. Меняются в приложении, виджеты обновляются сразу.

## Сборка

`./gradlew assembleRelease`. APK собирается автоматически GitHub Actions при каждом пуше в `main`.

# Dotify Widget

Виджет «сейчас играет» для главного экрана Android. Сделан под Dotify, но работает с любым плеером, который показывает медиауведомление.

**[Скачать последнюю версию](../../releases/latest)**

## Возможности

- Большой виджет 4×2 и мини 4×1: обложка, трек, исполнитель, прогресс, управление.
- 7 оформлений, включая Liquid Glass в стиле iOS 26, с живым превью.
- Переливающийся фон в стиле «Моей волны» из цветов обложки, плавная смена при переключении трека.
- Фон может течь в темпе музыки (по желанию, доступ к микрофону, только громкость).
- Android 8.0 и новее.

## Установка

Подробная инструкция, включая обход блокировки Play Защиты, есть в описании каждого [релиза](../../releases/latest).

## Как это устроено

- `MediaListener` — сервис доступа к уведомлениям: находит активный плеер через `MediaSessionManager` и следит за треком.
- `Widgets` — сборка `RemoteViews`, кнопки управления, частичные обновления прогресса раз в секунду.
- `ThemeColors`, `CoverTone` — цвета тем из обложки (библиотека Palette), монохромный режим для чёрно-белых обложек.
- `Glass` — отрисовка стекла Liquid Glass.
- `Wave`, `Beat` — переливающийся фон: 12 заранее нарисованных кадров в `ViewFlipper`, скорость от громкости через `Visualizer`.

## Сборка

```
./gradlew assembleRelease
```

GitHub Actions собирает APK при каждом пуше в `main` и публикует релиз `v1.<номер сборки>`.
